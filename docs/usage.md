# 操作方法

beanKeyを選択した状態で使う操作の一覧です。LinuxのFcitx5とmacOSで共通する操作を記載します。macOSの`Option`キーは、表中の`Alt`に相当します。入力方式や予測などの設定は[設定リファレンス](configuration.md)を参照してください。

「入力中」は読みを編集中、「プレビュー中」は候補をプリエディットに表示中、「候補選択中」は候補一覧を表示中の状態です。`liveConversion = true`（初期値）の場合、入力中の`Space`は直接候補選択へ進みます。`false`の場合は、最初の`Space`でプレビューし、次の`Space`で候補一覧を開きます。

## 入力と変換

| 操作 | 場面 | 動作 |
| --- | --- | --- |
| 文字キー | 入力中・未入力 | 設定した入力方式で文字を入力します。候補選択中に新しい文字を入力すると、表示中の文字列を確定して次の入力を始めます。 |
| `Space` | 入力中・プレビュー中・候補選択中 | 変換を開始し、プレビューから候補一覧を開きます。候補選択中は次の候補へ進みます。 |
| `↓` | 入力中・プレビュー中・候補選択中 | 候補一覧を開くか、次の候補へ進みます。 |
| `Shift+Space` / `↑` | 候補選択中 | 前の候補へ戻ります。先頭で`↑`を押すと、表記変換の候補を追加表示できます。 |
| `1`から`9` / 候補をクリック | 候補選択中 | 表示中の番号に対応する候補を選んで確定します。 |
| `Enter` | 入力中・プレビュー中・候補選択中 | プリエディットまたは選択中の候補を確定します。文節が残る場合は、残りの入力を続けられます。 |
| `→` | 候補選択中 | 選択中の文節を確定し、残りの文節の候補選択を続けます。 |
| `Shift+←` / `Shift+→` | 入力中・プレビュー中・候補選択中 | 変換する文節の範囲を短く、または長くして候補を更新します。 |
| `Backspace` | 入力中・プレビュー中・候補選択中 | 直前の入力を削除します。候補表示中も読みの削除へ戻ります。 |
| `Escape` | 候補選択中・プレビュー中・入力中 | 候補選択を戻し、次にプレビューを戻します。入力中に押すと、入力中の文字列を取り消します。ライブ変換が有効な場合、候補選択から直接入力中へ戻ります。 |
| `Tab` | 入力中に予測が表示されているとき | 表示中の予測を入力へ取り込みます。 |

入力がない状態の`Space`は空白を入力します。日本語入力時の全角・半角と`Shift+Space`の関係は、`conversion.typeHalfSpace`で切り替えられます。候補選択中の`0`は、表示中の文字列を確定して新しい`0`の入力を始めます。

## 表記の確定

入力中・プレビュー中・候補選択中に、次のキーで表記を変換して確定します。

| 操作 | 確定する表記 |
| --- | --- |
| `F6` / `Ctrl+J` | ひらがな |
| `F7` / `Ctrl+K` | カタカナ |
| `F8` / `Ctrl+;` | 半角カナ |
| `F9` / `Ctrl+L` | 全角英数 |
| `F10` / `Ctrl+:` / `Ctrl+'` | 半角英数 |

## そのほかのキー操作

| 操作 | 場面 | 動作 |
| --- | --- | --- |
| `Ctrl+H` | 入力中・プレビュー中・候補選択中 | `Backspace`と同じです。 |
| `Ctrl+P` | 候補選択中 | `↑`と同じです。 |
| `Ctrl+N` | 入力中・プレビュー中・候補選択中 | `↓`と同じです。 |
| `Ctrl+M` | 入力中・プレビュー中・候補選択中 | `Enter`と同じです。 |
| `Ctrl+F` | 候補選択中 | `→`と同じです。 |
| `Ctrl+I` / `Ctrl+O` | 入力中・プレビュー中・候補選択中 | それぞれ`Shift+←` / `Shift+→`と同じです。 |
| `Ctrl+Backspace` / `Ctrl+Delete` | 候補選択中 | 選択中の候補に対する学習結果を忘却します。学習が書き込み可能な場合に使えます。 |
| `Ctrl+Shift+U` | Unicode入力中を除く | Unicodeコードポイント入力を始めます。16進数を入力して`Enter`または`Space`で確定し、`Escape`で取り消します。 |
| `英数` / `かな`キー | Unicode入力中を除き、対応するキーがある場合 | 英語入力 / 日本語入力へ切り替えます。 |

Unicodeコードポイント入力中は`Backspace`で末尾の数字を消せます。無効なコードポイントを確定すると、文字を挿入せずに入力を終了します。

## 候補の操作と設定による違い

- 候補の「忘却」は、LinuxではFcitx5の候補アクション、macOSでは候補のコンテキストメニューからも実行できます。学習データ全体の消去は、Linuxでは入力メソッドのステータス領域の「Reset learning」、macOSでは入力メニューの「学習データを消去」から行います。
- 言語モデルによる入力訂正を有効にした場合、候補アクションの「Correct typos」（Linux）または「入力を訂正する」（macOS）から訂正候補を表示できます。
- `Alt`を押しながら句読点や記号を入力すると、設定に応じて別の記号を入力できます。`conversion.optionDirectFullWidthInput`を有効にすると、未入力時に`Alt`または`Shift+Alt`と文字キーで全角の英数字・記号を直接入力できます。
